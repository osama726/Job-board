# Job Board System 🚀

A professional Job Board platform built with **Laravel** and containerized using **Docker**. This project consists of two main applications serving different parts of the system.

## 🏗 Project Architecture

The project is structured as a monorepo containing:
- **job-app**: The main application for job seekers.
- **job-backoffice**: The administrative dashboard for managing jobs and users.
- **Dockerized Services**: MySQL 8.0 and phpMyAdmin for database management.

---

## 🛠 Tech Stack

- **Backend:** PHP & Laravel
- **Database:** MySQL 8.0
- **Environment:** Docker & Docker Compose
- **Tools:** phpMyAdmin
